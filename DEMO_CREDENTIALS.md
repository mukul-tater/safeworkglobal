# Demo credentials

**Do not store real passwords in this repository.**

For local / preview seeding:

1. Use the in-app seed flow (`/seed-data`) if available, **or**
2. Create accounts via the register pages and promote roles in Supabase / Lovable Cloud.

Admin access is controlled by the whitelist in `src/lib/adminAuth.ts` and matching DB role.

If you keep private login notes, put them outside the repo (password manager) — never commit them.
